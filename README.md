## 🧮 CodeAlpha Calculator

A modern and responsive calculator web application built using **HTML, CSS, and JavaScript**.

### ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🗑️ Clear and delete functions

- 🌙 Dark mode / ☀️ Light mode
